# TUVA İHA TAKIMI – YAZILIM PROJESİ

## Proje Hakkında
Bu proje, İHA sistemlerinde kullanılacak yazılım altyapısını geliştirmek amacıyla hazırlanmıştır.

## Kullanılan Teknolojiler
- Python
- NumPy
- Matplotlib
- Git ve GitHub

## Proje Dosyaları
- `kelime_sayaci.py`
- `koordinatmesafesi.py`
- `min_max_hiz.py`
- `ortalama_hesaplama.py`
- `veri_filtresi.py`

## Projenin Hedefleri
- Python programlama becerilerini geliştirmek.
- Sensör verilerini işlemek.
- Koordinat ve hız hesaplamaları yapmak.
- İHA yazılım altyapısı oluşturmak.

## Geliştirme Süreci
TUVA İHA Takımı yoğun hafta programı kapsamında geliştirilmektedir.
